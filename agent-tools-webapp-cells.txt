## 🚀 Utvidet webapp med XAI og personlige helseråd

### Hvorfor begrense til 3 egenskaper?

Den enkle webappen over bruker kun **alder**, **BMI** og **glukosenivå**. Dette er et bevisst valg:

**Praktiske fordeler:**
- 🎯 **Brukervennlighet:** Færre input-felt = enklere å bruke
- ⏱️ **Tilgjengelighet:** Disse verdiene er ofte kjent eller lett målbare
- 📊 **Viktigste prediktorer:** Vår XAI-analyse viste at glucose og BMI er de viktigste egenskapene

**Men det er en trade-off:**
- ❌ Modellen bruker gjennomsnittsverdier for de andre 5 egenskapene
- ❌ Dette kan gi mindre nøyaktige prediksjoner for individuelle pasienter
- ❌ Vi mister viktig informasjon (f.eks. familiehistorie via `dpf`)

### Utvidet versjon med flere egenskaper

I den utvidede webappen under inkluderer vi **flere egenskaper** og legger til:

1. **🔢 Probabilistisk prediksjon** - Ikke bare "ja/nei", men sannsynlighet
2. **📊 XAI-forklaring** - Hvilke faktorer bidrar mest til prediksjonen
3. **💊 Personlige helseråd** - Konkrete anbefalinger basert på verdiene
4. **🎨 Visuell risiko-indikator** - Fargekoding av risikonivå

import gradio as gr

# Referanseverdier for sammenligning (fra datasettet)
reference_values = {
    'pregnancies': {'mean': diabetes['pregnancies'].mean(), 'healthy_max': 4},
    'glucose': {'mean': diabetes['glucose'].mean(), 'healthy_max': 100, 'prediabetes': 125, 'diabetes': 126},
    'diastolic': {'mean': diabetes['diastolic'].mean(), 'healthy_max': 80, 'high': 90},
    'bmi': {'mean': diabetes['bmi'].mean(), 'normal_max': 25, 'overweight': 30, 'obese': 35},
    'dpf': {'mean': diabetes['dpf'].mean(), 'low_risk': 0.3, 'high_risk': 0.7},
    'age': {'mean': diabetes['age'].mean(), 'risk_increase': 45}
}

def get_risk_level(probability):
    """Kategoriserer risikonivå basert på sannsynlighet."""
    if probability < 0.3:
        return "🟢 LAV RISIKO", "green"
    elif probability < 0.5:
        return "🟡 MODERAT RISIKO", "orange"
    elif probability < 0.7:
        return "🟠 FORHØYET RISIKO", "darkorange"
    else:
        return "🔴 HØY RISIKO", "red"

def generate_xai_explanation(input_values, probability, feature_importances):
    """Genererer en forklarbar AI-analyse av prediksjonen."""
    
    # Feature-navn i samme rekkefølge som modellen forventer
    feature_names = ['pregnancies', 'glucose', 'diastolic', 'triceps', 
                     'insulin', 'bmi', 'dpf', 'age']
    
    # Beregn bidrag fra hver feature (forenklet metode)
    contributions = []
    for i, (name, value) in enumerate(zip(feature_names, input_values)):
        ref = reference_values.get(name, {})
        mean = ref.get('mean', value)
        importance = feature_importances[i]
        
        # Beregn avvik fra gjennomsnitt
        if mean > 0:
            deviation = (value - mean) / mean
        else:
            deviation = 0
            
        # Bidrag = viktighet × avvik (forenklet)
        contribution = importance * deviation
        contributions.append((name, value, mean, contribution, importance))
    
    # Sorter etter absolutt bidrag
    contributions.sort(key=lambda x: abs(x[3]), reverse=True)
    
    # Bygg forklaring
    explanation = "## 📊 XAI-ANALYSE: Hva påvirker prediksjonen?\n\n"
    explanation += "| Egenskap | Din verdi | Gjennomsnitt | Bidrag |\n"
    explanation += "|----------|-----------|--------------|--------|\n"
    
    for name, value, mean, contrib, imp in contributions[:5]:  # Top 5
        direction = "↑ øker" if contrib > 0 else "↓ senker"
        explanation += f"| {name} | {value:.1f} | {mean:.1f} | {direction} risiko |\n"
    
    return explanation

def generate_health_advice(glucose, bmi, diastolic, age, dpf, probability):
    """Genererer personlige helseråd basert på input-verdier og prediksjon."""
    
    advice = []
    urgent = []
    
    # Glukose-vurdering
    if glucose >= 126:
        urgent.append("⚠️ **GLUKOSE KRITISK HØY** ({:.0f} mg/dL): Dette er over diabetesgrensen. Oppsøk lege snarest!".format(glucose))
    elif glucose >= 100:
        advice.append("🔶 **Glukose forhøyet** ({:.0f} mg/dL): Du er i prediabetes-området (100-125). Vurder kostholdsendringer.".format(glucose))
    else:
        advice.append("✅ **Glukose normal** ({:.0f} mg/dL): Bra! Verdien er under 100.".format(glucose))
    
    # BMI-vurdering
    if bmi >= 35:
        urgent.append("⚠️ **BMI SVÆRT HØY** ({:.1f}): Fedme grad 2+. Snakk med lege om vektnedgang.".format(bmi))
    elif bmi >= 30:
        advice.append("🔶 **BMI høy** ({:.1f}): Fedme grad 1. Mål: Reduser 5-10% av kroppsvekten.".format(bmi))
    elif bmi >= 25:
        advice.append("🔶 **BMI lett forhøyet** ({:.1f}): Overvekt. Øk fysisk aktivitet og vurder kosthold.".format(bmi))
    else:
        advice.append("✅ **BMI normal** ({:.1f}): Bra! Hold vekten stabil.".format(bmi))
    
    # Blodtrykk-vurdering
    if diastolic >= 90:
        urgent.append("⚠️ **DIASTOLISK BLODTRYKK HØY** ({:.0f} mmHg): Hypertensjon. Bør følges opp av lege.".format(diastolic))
    elif diastolic >= 80:
        advice.append("🔶 **Blodtrykk lett forhøyet** ({:.0f} mmHg): Vurder saltreduksjon og mosjon.".format(diastolic))
    else:
        advice.append("✅ **Blodtrykk normalt** ({:.0f} mmHg): Bra!".format(diastolic))
    
    # Alder og familiehistorie
    if age >= 45:
        advice.append("ℹ️ **Alder over 45**: Økt risiko. Anbefaler årlig screening.")
    
    if dpf >= 0.5:
        advice.append("ℹ️ **Familiehistorie**: Din DPF-verdi ({:.2f}) indikerer genetisk disposisjon.".format(dpf))
    
    # Samle resultat
    result = "## 💊 PERSONLIGE HELSERÅD\n\n"
    
    if urgent:
        result += "### 🚨 Krever oppmerksomhet:\n" + "\n".join(urgent) + "\n\n"
    
    result += "### 📋 Vurdering av dine verdier:\n" + "\n".join(advice) + "\n\n"
    
    # Generelle anbefalinger basert på risikonivå
    if probability >= 0.5:
        result += """### 🎯 Anbefalte tiltak ved forhøyet risiko:
1. **Kosthold:** Reduser sukker og raffinerte karbohydrater
2. **Mosjon:** 150 min moderat aktivitet per uke (rask gange, sykling)
3. **Vekt:** Mål om 5-7% vekttap hvis BMI > 25
4. **Oppfølging:** Bestill time hos fastlege for HbA1c-test
5. **Monitorering:** Mål blodsukker regelmessig hvis tilgjengelig
"""
    else:
        result += """### 🎯 Forebyggende tiltak:
1. **Oppretthold** sunne vaner med balansert kosthold
2. **Fortsett** med regelmessig fysisk aktivitet
3. **Årlig screening** anbefales fra 45 år
"""
    
    return result

def predict_diabetes_extended(pregnancies, glucose, diastolic, triceps, insulin, bmi, dpf, age):
    """
    Utvidet prediksjonsfunksjon med XAI og helseråd.
    Returnerer prediksjon, sannsynlighet, XAI-forklaring og helseråd.
    """
    
    # Forbered input som DataFrame med riktige kolonnenavn (unngår sklearn-advarsel)
    feature_names = ['pregnancies', 'glucose', 'diastolic', 'triceps', 
                     'insulin', 'bmi', 'dpf', 'age']
    input_data = pd.DataFrame([[pregnancies, glucose, diastolic, triceps, 
                                insulin, bmi, dpf, age]], columns=feature_names)
    
    # Prediksjon og sannsynlighet
    prediction = rf.predict(input_data)[0]
    probability = rf.predict_proba(input_data)[0][1]  # P(diabetes)
    
    # Risikonivå
    risk_level, color = get_risk_level(probability)
    
    # Hovedresultat
    main_result = f"""# 🩺 DIABETES RISIKOVURDERING

## {risk_level}

**Predikert sannsynlighet for diabetes: {probability:.1%}**

{"🔴 Modellen predikerer **DIABETES**" if prediction == 1 else "🟢 Modellen predikerer **IKKE DIABETES**"}

---

⚠️ **VIKTIG ANSVARSFRASKRIVELSE:**
Dette er en demonstrasjonsmodell basert på et begrenset datasett fra 1988.
Resultatene skal **IKKE** brukes til medisinske beslutninger.
Kontakt alltid kvalifisert helsepersonell for reelle helsebekymringer.

---
"""
    
    # XAI-forklaring
    feature_importances = rf.feature_importances_
    xai_explanation = generate_xai_explanation(
        [pregnancies, glucose, diastolic, triceps, insulin, bmi, dpf, age],
        probability,
        feature_importances
    )
    
    # Helseråd
    health_advice = generate_health_advice(glucose, bmi, diastolic, age, dpf, probability)
    
    # Kombiner alt
    full_output = main_result + xai_explanation + "\n---\n\n" + health_advice
    
    return full_output
