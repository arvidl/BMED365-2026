# Literature Synthesis - Prompt Templates

These templates demonstrate structured approaches to using LLMs for literature review and research synthesis, particularly useful for the Team Project.

> **IMPORTANT**: Always verify citations and facts. LLMs can hallucinate references that don't exist.

---

## 1. Systematic Literature Summary

```
ROLE: You are a research assistant helping with a literature review.

TOPIC: Deep learning methods for glioblastoma segmentation from MRI

TASK: Summarize the key developments in this field following this structure:

1. **Overview** (2-3 sentences on the field)

2. **Key Methods Categories**:
   - List main approaches (e.g., U-Net variants, Transformers, etc.)
   - Brief description of each

3. **Benchmark Datasets**:
   - BraTS challenge: purpose, data, metrics
   - Other relevant datasets

4. **State-of-the-Art Performance**:
   - Current best methods
   - Performance metrics (Dice score ranges)
   - Remaining challenges

5. **Recent Trends** (2023-2025):
   - New directions
   - Emerging techniques

6. **Gaps in Literature**:
   - What remains understudied
   - Opportunities for future research

FORMAT: Structured with clear headings
CITATIONS: Note that I should verify all references independently
```

## 7. Citation Verification Checklist

```
IMPORTANT: Before using any AI-generated citation, verify:

□ Authors - Do these authors exist and work in this field?
□ Title - Is this the exact title? (Search Google Scholar)
□ Journal - Does this journal exist? Is it reputable?
□ Year - Does the publication year match?
□ DOI - Can you access the paper via the DOI?
□ Content - Does the paper actually say what the AI claims?

COMMON AI CITATION ERRORS:
- Inventing plausible-sounding papers that don't exist
- Mixing up authors between papers
- Attributing findings to wrong papers
- Creating fake DOIs
- Misrepresenting paper conclusions

VERIFICATION TOOLS:
- Google Scholar
- PubMed
- Semantic Scholar
- Connected Papers
- Publisher websites

WHEN IN DOUBT: If you can't find a paper, don't cite it.
```
