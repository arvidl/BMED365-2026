## Preparation

### Before the course starts

1. **Create a Google account** (if you don't have one)
   - Go to [accounts.google.com](https://accounts.google.com) and follow the instructions
   - We use Google Colab which requires Google login

2. **Test that Colab works**
   - Go to [colab.research.google.com](https://colab.research.google.com)
   - Click "New notebook"
   - Type `print("Hello!")` in the cell and press Shift+Enter
   - If you see "Hello!" as output, you're all set!

3. **Optional: ChatGPT account**
   - Go to [chat.openai.com](https://chat.openai.com) and create a free account
   - Alternative: Use [chat.uib.no](https://chat.uib.no) (requires UiB login)

### Bring with you

- Laptop with browser (Chrome, Firefox, Safari, or Edge)
- Laptop charger
- Curiosity and an open mind!

## AI Tools We Use

### Google Colab with Gemini
Google Colab has built-in AI assistance via Gemini. Click the ✨ icon in the toolbar to:
- Generate code from description
- Get explanation of existing code
- Debug problems

### ChatGPT / Claude / chat.uib.no
External AI assistants can be used to:
- Ask questions about Python concepts
- Request code examples
- Get help understanding error messages

> **Tip:** AI is a helpful partner, but not a replacement for understanding. Always try to understand *why* the code works!
